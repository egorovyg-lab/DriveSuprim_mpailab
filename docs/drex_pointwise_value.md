# Добавочная ценность сохранённых оценок Drex

Сравниваем исходную траекторию DriveSuprim, числовое правило замены и два его
варианта с дополнительным признаком Drex. Признак равен разности оценки
кандидата и исходной траектории в одной сцене. Белый фон и дорожный кадр
проверяются отдельно. Все три правила получают один набор из 15 альтернатив
в `top16`.

Входы на msu270 берутся из завершённого `pointwise_gpu4_v1` и из
`rollout_audit_drex_probe_v1`. Контроль сверяет SHA кеша, сцену, сессию,
физический ID кандидата и его ранг. Числа симуляции идут в обучающие цели
и оценку. Новые вызовы Drex и симуляции не нужны.

Четыре внешние части разделены по целым сессиям. Внутренние отложенные
сессии используются для калибровки и подбора порога замены с бюджетом 10%
сцен. Для допуска также нужны положительный прогноз изменения PDM и
оценки риска ухудшения компонентов и нарушения бюджета прогресса до 0,10.
Из допущенных выбирается максимум прогнозируемой вероятности полезной
замены. Полезная замена повышает PDM на 0,5 п.п. или больше, сохраняет
прочие компоненты и укладывается в бюджет потери прогресса DriveSuprim.

Отдельно отчёт показывает сравнение при одинаковом числе замен по
внешним частям, с бюджетами до 5%, 10% и 20%. Для этой диагностики сцены
упорядочиваются по прогнозам в каждой внешней части, без использования
её исходов. Если допустимых сцен меньше бюджета хотя бы у одного варианта,
все варианты используют меньшее число замен. Отчёт публикует фактическое
число замен и парные интервалы по сессиям. Сцены относятся к уже изученному
TRAIN.

## Запуск на msu270

Пилот строит прогнозы для одной внешней части и проверяет весь путь от
сохранённых баллов до сравнения. Основной запуск переиспользует этот
чекпоинт и добавляет остальные три части.

```bash
cd ~/drivesuprim && git pull --ff-only
# 1. Пилот
bash scripts/drex/run_pointwise_value.sh submit-pilot
bash scripts/drex/run_pointwise_value.sh status
# 2. Основной запуск после pilot_complete
bash scripts/drex/run_pointwise_value.sh submit-full
```

Статус `complete` и отчёт `report.json` находятся в
`/scratch/pr0201/drex_runtime/runs/pointwise_value_v1`. Для дальнейшего
разбора нужен только этот отчёт.
