# DriveMem: исследовательский отчёт

Дата среза: 7 ноября 2026 года. Язык: русский. Объём PDF: 25 страниц.

## Основные файлы
- report.tex — самодостаточный исходник LaTeX с формулами и всеми таблицами.
- report.pdf — собранный и визуально проверенный PDF.
- build.ps1 / build.sh — сборка XeLaTeX в два прохода.
- evidence_extracted.json — извлечённые JSON-объекты из переданных серверных выводов.
- source_manifest.json — исходные файлы, SHA256 и локальный git HEAD.
- evidence/ — копии использованных серверных текстовых вложений.
- SHA256SUMS.txt — контрольные суммы файлов комплекта.

## Сборка
Требуются XeLaTeX и пакеты fontspec, babel с русским языком, geometry,
amsmath, booktabs, tabularx, longtable, graphicx, xcolor, hyperref.
Основной шрифт: Times New Roman; резервные Liberation Serif / CMU Serif.
Arial/Consolas имеют резервные DejaVu Sans / DejaVu Sans Mono.
Внешних картинок, .bib и дополнительных .tex inputs нет.

Windows: ./build.ps1
Linux/macOS: bash build.sh
Либо дважды выполнить: xelatex -interaction=nonstopmode -halt-on-error report.tex
На установленном локальном MiKTeX сборка проверена с отключённым auto-installer.

## Содержание
Воспроизведение v2/v1, oracle и human-filter аудит, подготовка данных,
остаточная память, action transfer, donor-capacity/score-ceiling диагностика,
полная top16-разметка, scalar utility, расширение M/F, bounded component models,
decoder features, численная воспроизводимость, пост-аудитная функциональная
приёмка, все финальные методы, F-CV, отдельные вмешательства, ограничения
и статус пунктов исходного плана статьи.

## Происхождение и ограничения
Метрики переписаны из предоставленных пользователем серверных результатов.
При подготовке отчёта серверные запуски не повторялись; полного серверного
experiment directory в комплекте нет. Локальный код проверялся при описании
формул/протоколов. Результаты oracle и полного 152-scene численного аудита,
переданные непосредственно сообщениями чата, описаны в тексте; отдельной копии
исходного JSON этих сообщений в attachments не было.

Обе query-когорты — уже просмотренный development. Local PDM не равен EPDMS.
Нулевой observed harm не является калиброванной гарантией безопасности.
Primary последнего эксперимента — baseline; текущая гипотеза полезной памяти
не получила устойчивого подтверждения. Правило functional acceptance изменено
после численного аудита и явно отмечено как post-audit specification.

Текстовые названия работ в исходном плане не использовались как подтверждение
актуального литературного приоритета. Обновление literature review — отдельная задача.
